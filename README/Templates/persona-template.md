PERSONA TEMPLATE — USAGE NOTES

PURPOSE:
Persona files give an AI a borrowed operating system — the decision-making
instincts and craft standards of a specific practitioner. They are NOT
biographies. They are instruction sets written in someone else's voice.

WHAT MAKES A GREAT PERSONA FILE:

1. TITLE IS A PHILOSOPHY, NOT A NAME
   Bad:  "David Ogilvy" / "Jony Ive"
   Good: "Make Ideas Impossible to Ignore" / "Every Detail Is a Decision"
   The title primes the AI with the persona's core operating principle
   before it reads a single rule.

2. NUMBERED LAWS CREATE HARD CONSTRAINTS
   5-10 non-negotiable rules. Bold the hook. These are the guardrails
   that prevent the AI from drifting into generic output. Every law
   should be falsifiable — if it can't be violated, it isn't useful.

3. VOICE, NOT BIOGRAPHY
   Zero "born in 1911." Zero career history. Write in the persona's
   cadence, use their metaphors, channel their intensity. The AI needs
   to think like this person, not recite facts about them.

4. SPECIFICITY IS THE WHOLE GAME
   "Bath towels weigh three pounds" not "luxury hotel."
   "Spacing signals care or indifference" not "good design matters."
   Vague principles produce vague output.

5. DOMAIN-MAPPED SECTIONS
   Each expanded section should map to a task the AI will actually
   perform. Ogilvy's sections map to writing copy. Ive's sections map
   to designing interfaces. Don't include principles the AI can't act on.

6. ONE SIGNATURE TECHNIQUE
   Every master has a move. Ogilvy has "the touch of singularity."
   Ive has "earn simplicity." Name it, explain it, make it the thing
   the AI reaches for when the output feels flat.

7. NO FILLER
   Apply the persona's own standards to the persona file. If Ogilvy
   would cut 30% of the words, cut 30% of the words. If Ive would
   strip the chrome, strip the chrome.

8. EVERY HEADLINE IS A COMMAND
   Headlines must use imperative verb phrases. Active voice. Prescriptive.
   Bad:  "Core Beliefs" / "Craft Approach" / "Signature Technique"
   Good: "Be Specific" / "Earn Simplicity" / "Inject the Touch of Singularity"
   Descriptive headlines produce descriptive output. Commands produce action.
   The AI mirrors the energy of the headings — noun-phrase labels beget
   noun-phrase labels all the way down.

STRUCTURAL RULES:
- Target length: 40-80 lines (the persona's voice, concentrated)
- Title: Operating principle, not the person's name
- Headlines: Imperative verb phrases — commands, not labels
- Laws section: 5-10 numbered, bolded, one-line each
- Voice sections: 2-4 expanded sections with subsections as needed
- No code blocks (persona files are pure craft guidance)
- End with momentum — last line should propel, not summarize

WHERE PERSONA FILES LIVE:
- Persona definition: .claude/skills/[persona-name]/[persona-name].md
- Skill wrapper:      .claude/skills/[persona-name]/SKILL.md
- The SKILL.md routes the AI to the persona file and defines when
  to activate it. The persona .md file IS the operating system.

WHEN TO CREATE A NEW PERSONA:
- You need the AI to produce output in a specific practitioner's style
- The domain has recognized masters whose instincts differ from defaults
- Generic AI output isn't good enough for this surface of the product
- The persona's principles can be expressed as actionable constraints
