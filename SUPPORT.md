# Support

Use GitHub Issues for bugs, setup failures, and feature requests:

<https://github.com/mattmireles/local-motion/issues>

When reporting a setup issue, include:

- macOS version and chip family.
- VS Code or Cursor version.
- Local Motion version.
- Hugging Face GGUF repository and quantization.
- Whether `llama-server` is installed on `PATH`, `/opt/homebrew/bin`, or
  `/usr/local/bin`.
- The exact Local Motion error message.

Do not include private code, private prompts, API keys, or model outputs that
contain sensitive information.
