# Suggested Commands

- Install deps: `npm install`.
- Compile extension: `npm run compile`.
- Type-check without emit: `npm run check`.
- Watch TypeScript: `npm run watch`.
- Lint TS source: `npm run lint`.
- Run tests: `npm test`.
- Build VSIX package: `npm run package`.
- Open in VS Code/Cursor and run Extension Development Host, then command `Local Motion: Open Setup` for manual runtime checks.
- There is no `npm run typecheck`, no `verify:generated`, no workspace package script, no Wrangler/Firebase deploy in this repo.
